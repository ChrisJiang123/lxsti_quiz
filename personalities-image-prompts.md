# 留学生 16 人格 · AI 图片生成 Prompt 集

每个人格都包含：**中文概念**（给你自己看）+ **Prompt（英文）**（直接复制丢给 Midjourney / DALL·E / nano-banana / Flux / Sora）。

---

## 🎨 统一风格基线（强烈建议）

为了让 16 张图能像一套系列作品，建议所有图都加上同一段风格后缀。推荐两个方向，二选一或换成你自己的：

### 方向 A · Zine / Risograph（跟 App 美学一致，最推荐）
```
editorial illustration, risograph print aesthetic, limited color palette of cream beige, tomato red, mustard yellow, teal, ink black, bold confident linework, slight misregistration, grainy paper texture, flat color blocks, playful zine magazine style, 9:16 portrait
```

### 方向 B · 3D 盲盒手办风（小红书爆款向）
```
cute 3D character figurine, pop mart style, soft pastel lighting, full body shot, clean studio background, chibi proportions, Pixar-inspired, detailed accessories, 9:16 portrait, professional product photography
```

把方向 A 或 B 粘到每个 prompt 的最后就行。下面每条 prompt 我只写"角色和场景"部分。

---

## 使用提示

- 想让 16 张人物看起来像"同一个世界的人"，保持东亚年轻成年人 (east asian young adult, early 20s, college student) 这个基底一致
- 性别可以自己调整：`male` / `female` / `androgynous` / `non-binary` / `student`
- Midjourney 建议加 `--ar 9:16 --style raw` 参数
- DALL·E / nano-banana 直接粘文字就行
- 如果某个 prompt 的画面不够戳，可以把**括号里的那句 essence 关键词**权重拉高，Midjourney 可以用 `::2` 后缀

## 💡 高效生成建议

1. **先测一张看效果**：挑一个你最能共情的人格先跑，确认风格基线 OK 再批量
2. **保持种子一致**：如果用 Midjourney，建议用 `--seed` 参数让 16 张的画风更统一
3. **批处理**：可以把 16 段 prompt 做成 Airtable / Notion 表格，一次性提交到 API
4. **后期统一**：生成后用 Lightroom / VSCO 批量套同一个预设，让 16 张更像系列

## 📐 尺寸建议

- **小红书封面**：9:16（1080×1920）或 3:4（1080×1440）
- **朋友圈九宫格**：1:1（1080×1080），需要裁剪
- **App 里的结果页 emoji**：512×512 透明背景
- **分享海报**：就用当前的 9:16 海报模板，图片占上半，下半放代码和 tagline
